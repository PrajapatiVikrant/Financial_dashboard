# 💰 Responsive Finance Dashboard

A modern, fully responsive **personal finance dashboard** built using **HTML, CSS, and JavaScript**.  
It helps users manage and visualize their **income, expenses, investments, and spending** through interactive charts, responsive tables, and a clean mobile-friendly interface.

---

## 🚀 Features

- 📊 **Dashboard Overview** — View income, expenses, and investment summaries at a glance.  
- 💸 **Add / Edit / Delete Transactions** — Manage your financial records with ease.  
- 🧩 **Dynamic Filters** — Filter data by category or type for quick insights.  
- 📱 **Fully Responsive Design** — Optimized layout for desktop, tablet, and mobile.  
- 🧾 **Interactive Tables** — Scrollable and touch-friendly transaction lists.  
- 🔔 **Real-time Toast Notifications** — Get instant feedback for all user actions.  
- 🌙 **Accessible UI** — Keyboard and screen-reader-friendly design.  

---

## 🛠️ Technologies Used

| Technology | Purpose |
|-------------|----------|
| **HTML5** | Structure and layout |
| **CSS3** | Styling and responsive design |
| **JavaScript (Vanilla)** | Logic, interactivity, and DOM manipulation |
| **Chart.js (optional)** | Data visualization (charts and graphs) |

## 🖥️ How to Run This Project Locally

Follow these steps to set up and run the project on your system using **Git Bash** 👇  

### 1️⃣ Clone the Repository
Open **Git Bash** or **cmd** in your desired folder and run:
```bash
git clone https://github.com/PrajapatiVikrant/Financial_dashboard.git
cd Financial_dashboard
```
## Run on Live Server

- Make sure you have the Live Server extension installed in VS Code.
- Open the index.html file.
- Right-click anywhere on the page and select “Open with Live Server.”
- Your project will now launch in the browser at http://localhost:5500 (or a similar port).
